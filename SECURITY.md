# Security Policy

## Reporting a Vulnerability

For vulnerabilities specific to uBlock Firefox Native, please open a [security advisory](https://github.com/itsrody/uBlockFirefoxNative/security/advisories/new) or a private report in the [issue tracker](https://github.com/itsrody/uBlockFirefoxNative/issues).

For vulnerabilities in the shared uBO core code, please follow the [upstream security policy](https://github.com/gorhill/uBlock/blob/master/SECURITY.md).
